=== fvm setup (prints the PATH line, with a legacy install in the way) -> exit 1
--- stdout
Wrote /fvm/shims/flutter
  -> /fvm/bin/fvm exec flutter

Add this line to /home/dev/.zshrc (/bin/zsh):

  export PATH="/fvm/bin:$PATH"

It has to go ahead of anything else that puts a flutter on PATH, and it only takes effect in shells started after you save the file.

fvm could add that line for you, but not yet: something in your startup files would beat it, or fvm could not read a file that might — see the warnings below.
Clear that first and start a new shell, then run: fvm setup --write-path-line

Then check it with: fvm doctor
--- stderr

WARNING: your shell defines its own `fvm`, which will win over the binary you just set up — a shell function or alias is resolved before PATH is ever searched.
  /home/dev/.zshrc:1: fvm() { echo the old one; }
Remove or comment out the line(s) above, then start a new shell.
